> **Electric Home** is a premium, high-end web experience designed for an elite electrical engineering firm in El Salvador. Combining **Minimalist Luxury** aesthetics with robust industrial functionality.

---

## 🎨 Design Philosophy: "Minimalist Luxury"

This project follows a cinematic and premium design paradigm:
- **Rich Aesthetics**: Deep "Ink" blacks, tailored HSL color palettes, and vibrant primary accents.
- **Dynamic Interactions**: Micro-animations using Framer Motion, glassmorphism effects, and custom scroll paradigms.
- **Cinematic Experience**: Horizontal layouts, Bento Grid galleries, and high-fidelity typography (Inter/Outfit).

---

## 🚀 Key Features

- **⚡ Emergency SOS Module**: Direct "Atención Inmediata" flow that activates a primary response protocol with WhatsApp integration.
- **🔧 Multi-Modal Service Catalog**: Interactive sections for Preventive Maintenance, Corrective Repairs, and New Installations.
- **📬 Server-Side Quotation System**: Robust contact form with automated email notifications via Zoho Mail integration.
- **🏗️ Industrial Bento Gallery**: A visually stunning showcase of projects using a modern grid layout.
- **📱 Ultra-Responsive UX**: Seamless experience across mobile, tablet, and desktop with a focus on touch-first interactions.
- **🛠️ Service Specialized Modules**: Dedicated components for Motors, Power Plants, and Energy Saving consultancy.
